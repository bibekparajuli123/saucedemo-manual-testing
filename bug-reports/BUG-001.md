# BUG-001: All product images display the same incorrect image for problem_user

**Severity:** Medium
**Priority:** Medium
**Module:** Inventory
**Environment:** Chrome (latest), Windows 11 — https://www.saucedemo.com/inventory.html

## Preconditions
Logged in as `problem_user` / `secret_sauce`

## Steps to Reproduce
1. Navigate to https://www.saucedemo.com/
2. Log in with username `problem_user` and password `secret_sauce`
3. Observe the product images on the inventory page
4. Click on any product to open its detail page
5. Observe the product image on the detail page

## Expected Result
Each product should display its own correct product image on both the inventory page and the product detail page.

## Actual Result
On the inventory page, every product displays the same incorrect image (a dog biting a cricket ball) instead of its actual product image. When the same product is opened on its detail page, the correct product image is displayed.

This inconsistency between the listing page and the detail page for the same product confirms the defect is in the image rendering on the inventory listing, not in the product data itself.

## Evidence
- Inventory page — same wrong image on all products:
  [View inventory screenshot](../evidence/screenshots/BUG-001-inventory.png)
- Product detail page — correct image shown:
  [Product detail page](../evidence/screenshots/BUG-001-detail.png)

## Impact
Users cannot visually identify products from the inventory listing. This severely hampers product browsing and may cause users to select the wrong item or abandon the site.

## Additional Notes
This behavior is specific to the `problem_user` account. Standard users see correct images. This confirms the bug is intentional / reproducible in the demo environment.
