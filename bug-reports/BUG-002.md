# BUG-002: Sort dropdown resets after adding item to cart

**Severity:** Low
**Priority:** Low
**Module:** Inventory
**Environment:** Chrome (latest), Windows 11 — https://www.saucedemo.com/inventory.html

## Preconditions
Logged in as `standard_user`

## Steps to Reproduce
1. Log in as standard_user
2. Sort products by "Price (low to high)"
3. Add any product to cart
4. Observe sort dropdown and product order

## Expected Result
Sort order remains "Price (low to high)" after adding to cart

## Actual Result
Sort dropdown resets to default "Name (A to Z)" and products re-order

## Evidence
See `evidence/screenshots/BUG-002.png`

## Impact
Minor UX issue — user loses their sort preference when adding items
