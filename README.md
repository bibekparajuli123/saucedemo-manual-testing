# SauceDemo Manual Testing Portfolio

Manual QA testing project for [SauceDemo (Swag Labs)](https://www.saucedemo.com/) — a demo e-commerce site built for testing practice.

## Project Scope
- **Modules tested:** Login, Inventory, Cart, Checkout
- **Test cases:** 40+ (positive, negative, boundary)
- **Bug reports:** 5–10
- **Techniques:** Equivalence partitioning, boundary value analysis, negative testing

## Repository Structure
- `test-cases/` — Markdown test cases organized by module
- `bug-reports/` — Documented bugs with steps to reproduce
- `execution/` — Test execution summary
- `evidence/` — Screenshots and evidence
